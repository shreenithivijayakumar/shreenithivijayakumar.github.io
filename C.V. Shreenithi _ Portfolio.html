Featured project

TodoFlow

A full-stack task manager. Users add, edit, complete and delete tasks, filter by All, Active or Completed, and see their progress at a glance on a dashboard with a completion ring. Priorities (Low, Medium, High) and categories help organise the list.

The Spring Boot REST API is kept separate from the React front end, so each side can be built and tested on its own.
